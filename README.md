

A high-end, responsive portfolio website featuring a modern dark-mode aesthetic with glassmorphism effects, gradient mesh backgrounds, and smooth scroll animations.

## 🚀 Live Demo
You can view the live site here: **[[Here](https://vaibhav25-mnnit.github.io/vaibhav-bagate/)]**

## 🛠️ Built With
- **HTML5 & CSS3**: Custom properties (variables), Flexbox, and CSS Grid.
- **Glassmorphism**: Backdrop filters and semi-transparent surfaces for a modern UI.
- **Animations**: CSS keyframes for orbs and marquee effects; Intersection Observer API for scroll-reveal animations.
- **Typography**: Space Grotesk (Headings), Inter (Body), and Fira Code (Accents/Mono).

## 📂 Project Structure
- `index.html`: Contains the core structure, styles, and interactive logic.
- `assets/`: (Optional) Folder for local images or PDFs (e.g., Resume).

## 🏗️ Local Development
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. To make changes, edit the internal `<style>` tag for CSS or the `<body>` for content.
